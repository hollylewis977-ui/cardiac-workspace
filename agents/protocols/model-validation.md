# 模型验证与个体化

按任务逐项记录，缺失写 not-assessed，不自动升级：
- code：单元/回归、前后向、梯度、checkpoint 重载、数据接口。
- numerics：生成器/算子一致性、dt/空间分辨率敏感性、守恒或范围约束是否真的适用。
- data：切分、时间隔离、PCA 拟合来源、重复样本和泄漏。
- prediction：固定选模后独立样本的完整未来窗口，对照与覆盖范围。
- personalization：个体条件、观测算子、可识别参数、校准数据和独立验证数据。
- uncertainty：多种子/样本差异、噪声和参数/域偏移敏感性，按证据报告区间。

当前 V/Ca 预测至少同时看全域 NRMSE、活动/波前误差、persistence 对照、激活漏检/误检、
匹配数与激活时间 MAE，以及随预测跨度变化的误差。记录 -20 mV 阈值和实际实现。
Scaler 固定范围为 V=[-100,50] mV、Ca=[0,0.0012] mM；归一化误差与物理误差分开。
没有匹配事件时 MAE=0 不能解释成准确；首次上穿也不能替代再次激活/复极检查。
APD、传导速度、ECG 等只有数据、定义与实现支持时才评估，不假定当前代码已具备。

检查 unclamped 和实际部署 clamp 的影响；纯 persistence 的全局误差可能较低但波前错误。
PCA 先做许可时间内的表示诊断，再评低维动力学，不能混淆重建误差和未来预测误差。
图差分监督不是完整 CRN 残差；V/Ca 总和不必守恒，不能凭直觉加总量守恒损失。
个体化方向后续必须单独引入几何/纤维/导电/刺激/离子参数等实际影响动力学的条件，
设计校准与验证，确认与现有二维合成任务的距离；不自动迁移到三维 crn/ 数据。
