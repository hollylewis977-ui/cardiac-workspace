# 数据与信息边界

检查来源、生成器版本、单位、NPZ 成员/形状/dtype、采样时刻、有限值、缺失和异常范围。
只读头信息只能确认结构；数值质量、节点一致性和重复样本需另外检查。
v10 常见成员 u/ca=[30,1001,43573]，x_uni/x_mesh=[30,43573,2]，full_init=[30,43573*21]；
以实际文件为准。内部 dt=0.02 ms，保存 2 ms，总时长 2000 ms，不从旧函数名推断 200 ms。
保持文件名排序与节点顺序，不对同一下标映射再次最近邻重排。

默认 train=batch_000..019，val=020..021，test=022..024（600/60/90 样本）。
确认集合非空、无重叠，检查初值/几何重复与近重复风险。真实患者按人拆分。
所有拟合（包括几何特征 PCA）只用允许的训练样本和时间；记录数据清单与基底哈希。

分别注明：
- 优化器看到的训练目标时间；
- 验证选模时间和规则；
- 测试观测截止；
- 最终评分窗口。
500 ms 监督 + 默认后半段验证，不等于开发全程未接触后半段。
AR 的 strict-validation 使用前半段锚点；Direct 当前没有同名开关，不能复制假参数。
只监督 500 ms 的 Direct 如需严格时间隔离，应新增有测试覆盖的选模方式或预先固定训练轮次。

测试预测可以读 0–500 ms 观测，不能读未来标签、未来差分、由测试未来拟合的 PCA/归一化或由真值选出的隐藏状态。
诊断中使用真值反馈要显式标成 oracle/teacher-forced，不能列为可部署预测能力。
