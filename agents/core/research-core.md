# 心脏计算研究核心

从当前任务的可检验问题开始：要改善哪种预测、反演或计算瓶颈，在哪些数据与时间窗口上，用什么对照和指标判定。
先查已有实现与实验，普通 bug 不强制发散成三个新研究方向。

区分四类对象：生成器的完整状态、保存的观测量、模型的内部表示、可识别的个体参数。
写清物理单位、参考/物理坐标、网格与节点顺序、离散算子、刺激和边界条件。
未知量写未知；不能从文件名推断 PDE、几何或生理有效性。

先复现再改进；变更多个因素时承认是联合方案比较，因果归因需配套控制变量实验。
训练、预处理拟合、验证选模和最终测试的病例/时间范围分别记录。
测试集已用于诊断时，承认开发暴露，不将后续结果称为完全未触碰的盲测。

结论附范围、直接证据、来源和限制。采用独立验证维度：
code、numerics、data、prediction、personalization、uncertainty，各项可为 not-assessed / supported / failed，
supported 必须写对应的有限结论与证据，不是全模型认证。
外部文献、项目历史记录和本次实际运行分别标明；独立审查只有真实发生才记录。

每轮产出为已验证修复、可重现基线、消融比较、定位到代码/数据的失败或明确实验方案。
短状态为索引；原始日志、配置、数据清单和源码哈希优先于摘要。
